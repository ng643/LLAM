2What the transformer actually reads

No sensor projector and no continuous slots: the state is text, embedded by the same frozen table as the prompt. Each control step renders as a fixed-width sentence (render_state), followed by one answer marker per question and closed by <|im_end|>. Questions are read at their markers, and the action at the closing marker. Move the sliders to re-render the sentence, and hover a token to see its role.

Tokens are split on whitespace for readability. Qwen's BPE splits numbers differently, which is why collate computes marker positions (ans_pos) from the real tokenization.

3ACT: halting, the convex combination, and ponder cost

Each cycle re-applies layers 22–23 to the same hidden state (it is never reset). The halting head emits p_n = σ(W·h_n + b). A position halts on the first cycle where Σp ≥ 1 − ε; that cycle gets the remainder R = 1 − Σp (Graves). The output is Σ α_n·h_n with Σα = 1 exactly (logged as mass_err). The compute cost ponder = Σ n·α_n enters the loss as τ·ponder, so it is penalised, never forced.

4Zero-init gates & LoRA: bit-identical to the trunk at step 0

Every add-on starts inert. PromptFusion returns h + tanh(g)·CrossAttn(state → prompt) with g = 0. The sinusoidal cycle tag enters as tanh(g_c)·tag(n) with g_c = 0, and LoRA's B is zero. Only one factor of each product is zeroed: out_proj keeps its default init, so the gate still receives a gradient.

5Speaking through the LM head: the JSON questionnaire

No per-question head exists. Each answer is softmax(h_marker · W[option_ids]ᵀ), where W is the LM head (151,936 × 896) restricted to that question's option tokens (QuestionBinding.option_weight). The schema is data: the self-test sends a different questionnaire (axis_x + a 4-level tilt) through the same weights. A small MLP head reads the 6 motor actions, and task_head reads the 4 tasks.
